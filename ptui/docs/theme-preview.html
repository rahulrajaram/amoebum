Amoebum Dark
Tokyo Night-inspired theme for the amoebum TUI. Built with ptui's define-theme DSL — every color, role, and style controlled through a single Lisp form.

08 — Theme DSL
Infrastructure
The define-theme Macro
Themes are first-class ptui objects. The macro expands to a struct definition, a defvar binding, and registration in the global theme registry. Parent themes provide fallback resolution for any role not explicitly defined.
Amoebum dark theme definition (abridged)
;; ptui/src/core/theme.lisp provides define-theme (define-theme amoebum-dark (:base :dark) ; inherit built-in dark base (:background (rgb 16 18 24)) (:foreground (rgb 220 226 236)) (:roles (:user-label :fg (rgb 224 175 104) :boldp t) (:assistant-label :fg (rgb 122 162 247) :boldp t) (:assistant :fg (rgb 220 226 236)) (:tool-label :fg (rgb 125 207 255) :boldp t) (:warning :fg (rgb 240 198 116) :boldp t) (:error :fg (rgb 242 143 173) :boldp t) (:status-bar :fg (rgb 160 170 186) :bg (rgb 30 36 46))) (:markdown (:code-background (rgb 36 42 54)) (:inline-code-background (rgb 36 42 54)) (:fence-color (rgb 58 70 86)) (:keyword-color (rgb 240 198 116)) (:heading-color (rgb 122 162 247))))
The macro validates all (rgb r g b) forms at compile time. Runtime resolution walks the parent chain: theme-resolve-role checks the current theme's roles hash, then the parent's, then the parent's parent.
