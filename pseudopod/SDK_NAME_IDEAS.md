# SDK Name Ideas (Moonshot Ecosystem)

## Decision

**`pseudopod`** — adopted 2026-02-13.

Rationale: the SDK is amoebum's client reaching into the Moonshot ecosystem. An amoeba extends pseudopods to interact with its environment; this SDK extends a pseudopod toward Moonshot's API. The name belongs to amoebum's world, not Moonshot's branding.

The package `:pseudopod` carries `:moonshot-common-lisp` as a nickname for backward compatibility.

## Previously Considered

1. `moonshot-sdk-cl` — clear ecosystem association, explicit language tag
2. `kimi-sdk-cl` — strict parity with Python `kimi-sdk`
3. `kosong-cl` — aligns with deeper `kosong` orchestration layer
4. `moonshot-common-lisp` — original name, kept as package nickname
